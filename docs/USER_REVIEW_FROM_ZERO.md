# 从零开始使用拾迹 Home 与人工审查

**当前界面已调整（2026-10-20）：** 按用户要求移除人工复核选项，改为置信度颜色筛选。请优先阅读 [当前界面说明](CONFIDENCE_DISPLAY.md)。以下人工审查步骤作为历史说明保留，不再适用于当前前端。

更新：2026-10-19。先看原视频，再决定一条主张能否成立。未看清的过程可以保留未知。

## 1. 打开系统

已启动时，打开 <http://127.0.0.1:8000/>，点击 **打开记忆工作台**；也可直接访问 <http://127.0.0.1:8000/workspace>。若服务停止，双击项目中的 `start.bat`，或运行：

```powershell
Set-Location 'F:\比赛\AI黑客松'
.\start.ps1
```

保留启动窗口；关闭或 Ctrl+C 会停止服务。目前只在本机使用，没有手机远程连接、实时摄像头或手机原生 App。

## 2. 选择已有录像，或上传新录像

第一次建议选择 **人工复核·桌面·6分34秒（真实历史候选）**，然后检查 **人工复核·柜格·3分钟（真实历史候选）**。已有结果不需要上传或从头识别。历史候选来自真实模型，不是人工标准答案。

新录像通过拖拽或上传按钮导入，确认方向和播放正常，再开始分析。建议先用30–90秒、动作清楚的片段。上传不调用模型；开始分析会调用视觉 API。上限24小时、64GiB，实际受剩余磁盘和预算限制；没有整段24小时实测。

“部分完成”或“已暂停”时使用 **继续分析**，保留成功窗口并处理剩余部分。恢复时仍截断或格式不合格的窗口可拆成更短片段，成功子片段也会保存。不要反复点“从头重新分析”；新分析产生新版本，旧版人工结论不会自动继承。日额度耗尽时，已有事件仍能人工审查。

## 3. 先观看原视频，记录自己的判断

先完整看一遍，记下关键物品、动作时间和最后可见位置，再与 AI 时间线比较。反复观看动作前、中、后的过程。

| 画面所见 | 能确认的范围 |
|---|---|
| 桌面看见电脑 | 该时刻可见于桌面 |
| 手伸向电脑，随后被人挡住 | 不能单独证明拿起或入包 |
| 同一电脑明确越过背包开口 | 才可能支持放入；仍需检查后续反证 |
| 后来电脑又在桌上 | 核对身份和取出过程，不凭片尾反推全部历史 |
| 物品与柜格二维重叠 | 辅助定位，不能证明进入内部 |

“最后一次看见”与“现在仍在那里”不同。遮挡、出画、未覆盖时段，都可能使当前位置未知。

## 4. 打开人工审查入口

重复观察默认折叠为“多次看见”，点击 **展开 N 条原始记录** 查看每次时间和证据，再点某条的 **人工核对此条**，可以直接进入该原事件的复核。时间线还有 **展开全部原始事件 / 折叠重复记录** 开关。折叠不会减少需审查的原始条数，不会把“多次看见”变成“始终在那里”。详见 [重复事件整理](EVENT_GROUPING.md)。

时间线可搜索物品名称，按观察、推测、未知或小时筛选。点击证据时间跳转原片，然后在时间线下方展开 **场景标定与人工复核**。

在 **② 核对事件与证据** 选择事件，或点 **下一条未审查事件**。列表显示原始 AI 主张，旁边显示当前状态。“AI复核支持”不是人工确认。

点击“定位原始证据”，查看原片前后过程。第一次优先检查电脑入包、放入/取出和柜格位置，然后逐条检查普通观察。

## 5. 免费补充真实证据帧

1. 将上方播放器定位到需要的时刻并暂停，例如动作结束后或片尾。
2. 保持待审查事件选中，点击 **补充当前片段证据（免费）**。
3. 系统在播放器当前时刻前后约3秒按2fps取真实帧，靠近首尾时裁剪到片长。这个操作只用本地视频，**不调用视觉 API**。
4. 查看画面和时间戳，点 **清空已选证据**，再勾选相关帧。通常2–6张即可，最多16张。需要时换播放时刻再次补充。
5. 要采用这些帧，必须通过 **保存人工纠正** 提交。仅点击“人工确认原事件”仍使用原来的证据。

补帧不会自动产生事实或人工结论。最新补帧和先前已选帧会显示，提交前检查是否误选不相关时间。

## 6. 对每条事件做出决定

填写 **复核说明（必填）**，写出看到的时间、物品和依据，再操作：

| 按钮 | 何时使用 |
|---|---|
| **人工确认原事件** | 原动作、目标和证据正确，你看清了过程 |
| **否定原事件** | 原主张与画面冲突，或该动作明确没有发生 |
| **标记无法确定** | 遮挡、模糊、缺帧使你无法判断 |
| **保存人工纠正** | 动作、位置或证据需要修改，包括采用补充帧 |

纠正时展开 **纠正动作、位置或证据**，选择动作和位置/目标，检查勾选帧，写明说明并保存。即使动作不变，仅换证据也走纠正流程。

例：**只有亲自核实后**才否定入包候选。如果某个较晚时刻明确看到电脑在桌面，可将该条纠正为“看见位于 → 对应桌面”，仅选支持该时刻的帧。不要把“未看到入包”写成“已证实从未入包”，也不要用晚期位置覆盖早期真实移动。

“人工确认原事件”确认的是原主张。若你赞同 AI 后续提出的另一种解释，也需通过人工纠正明确动作和证据。

保存后查看 **人工已审查 x / y 条**，再点 **下一条未审查事件**。否定和未知也计入已审查，因此 x=y 代表逐条判断完成，不代表全部确认发生。计数只覆盖已有候选；漏检动作还需另行记录，目前没有任意新增人工事件的入口。

## 7. 柜格位置标错时

1. 播放器暂停在柜格清楚的画面。
2. 展开 **① 标定桌面或柜格位置**，点击 **使用播放器当前画面**。
3. 拖出矩形，命名如“观看方向左侧上层开放格”，点击 **添加框选区域**，最后 **保存区域标定**。
4. 回到相应事件，纠正动作选“看见位于”，目标选刚保存的区域，选择对应时刻的证据，填写说明并保存。

左右按观看图像方向，并写清层数。标定只定义画面位置，不自动修正所有历史事件，也不能证明入包。机位变化后要重新标定。

## 8. 用问答检查是否生效

- “笔记本电脑最后在哪里出现？”
- “笔记本电脑被放入背包了吗？”
- “这个物品的移动经过是什么？”

如果 LifeReplay 选了其他物品，先清除选择，再按名称提问。点击答案证据，核对物品、时间、位置和人工状态。证据不足时未知是合理结果，不要为了确定答案勉强确认。

普通问答使用本地结构化记忆，不另发视觉请求。**AI 加密复核（1次请求）** 和 **AI 上下文推测（1次请求）** 是可选付费辅助，每次点击最多一次请求，不能替代人工判断。实际金额以网关账单为准。

## 9. 保存与撤销

人工操作保存到本机数据库，刷新后仍保留。在 **③ 复核历史** 查看过程。需要撤销时填写原因，再点 **撤销此事件人工修改**；历史保留。若提示版本变化，刷新后重新核对再提交。

审查期间保留原视频和数据库。重新分析是新版本，需要重新审查，不会继承旧版结论。

## 完成检查表

- 完整观看原片，另行记录漏检和身份混淆。
- 核对分析覆盖率，不能把部分完成当作全片已识别。
- 每条候选均有人工决定，包括无法确定。
- 纠正引用相关真实时刻；强动作有过程证据。
- 位置名称清楚，未混淆前后时间。
- 核对一次位置问答、一次动作问答，并点击引用回看。
- 刷新确认保存。开发样本的人工检查不能称作独立测试准确率。
