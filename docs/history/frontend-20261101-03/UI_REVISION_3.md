# 第三版：拆分实时摄像头与导入视频

日期：2026-11-02（北京时间）。开发目录：`hack_2026_AI/web-ui`。

## 页面与导航

- 主导航分别显示“产品介绍”“实时摄像头”“导入视频”，摄像头和录像工具不分页。
- 实时摄像头：`/workspace?view=camera`，只显示实时预览、会话事件、运行指标、检测与录像详情。访问过摄像头后，切换到其他入口每 10 秒读取一次状态，维持服务端报活而不下载预览画面；切换导航不会调用摄像头停止接口。关闭整个网页仍遵循原有约 30 秒自动停止机制。
- 导入视频：`/workspace?view=videos`，显示上传、录像库、分析任务、事件筛选、原片回放与证据问答。切换两个入口时保留所选录像与未提交的问题，后台任务仍由原有服务处理。
- 旧 `/workspace` 和有效的 `?video=v_...` 链接继续打开录像工具；刷新、浏览器前进后退恢复对应入口。
- 产品介绍保留四页分页。流程页摄像头按钮直达摄像头；录像按钮和案例直达导入视频。
- 手机抽屉与底部导航同步拆分；在线云环境打开摄像头入口会说明需要本机服务，并提供导入视频入口。

## 验证

- TypeScript 与 Vite 构建通过；原有 26 项前端测试通过。
- 37 项导航与布局检查通过，覆盖 320–1440px、两个入口、报活请求、旧链接、刷新、历史导航、录像选择、问题草稿、案例和云环境提示。
- 35 项摄像头与抽屉回归检查通过；32 项产品介绍分页检查通过。
- 浏览器模拟检查仅验证界面与接口调用行为，未连接真实摄像头，未触发真实模型分析。`mock-*.png` 均为明确标注的界面测试素材。
- `camera-desktop.png`、`videos-desktop.png` 为本机服务实际空状态截图；本机摄像头未启动，录像云分析尚待配置。

证据位于 `review/revision-3/`。早期 `review/` 和 `review/revision-2/` 文件保留其版本历史，本版可运行的检查入口为 `revision-3` 内脚本。

## 交付范围

只调整前端导航、呈现、链接及相关验证与说明，后端 API 与识别逻辑保持原样。原始交接目录与第一、第二版交付包保留。

本版压缩包包含 `frontend/src`、`frontend/public`、`frontend/tests`、`frontend/dist` 与必要的前端配置和说明，不包含模型、录像数据、本机环境或依赖目录。覆盖前端源码和 dist 后，通过已有后端服务访问上述 URL 即可。
