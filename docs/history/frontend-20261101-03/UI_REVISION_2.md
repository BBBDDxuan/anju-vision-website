# 第二版：丰富场景图与产品介绍分页

日期：2026-11-02（北京时间）。本文件补充 `UI_HANDOFF.md`，介绍页以本版说明为准。开发目录与8000启动方式不变。

## 用户反馈与改动

- 原简笔图过于简略：替换为丰富的居家场景图，包括老人、沙发、茶桌、绿植、家庭陈设与墙面摄像头。
- 原产品介绍是连续长页面，容易只看到下一节的一部分：拆为产品概览、核心能力、使用流程、接入计划四个独立页面。
- 支持顶部分页、侧栏直达、上一页/下一页；首尾边界按钮禁用。
- 地址保留当前介绍页，刷新、直接链接、浏览器前进后退均能恢复；手机底栏同步选中项。
- 桌面翻页栏独立显示。低高度窗口做紧凑适配；更小窗口或放大字体时，当前页仍可滚动，不裁掉内容。
- 小屏仅展示当前页，允许自然纵向滚动；翻页后回到页首。

## 场景素材

`frontend/public/assets/home-care-scene.png` 为本轮使用内置图像生成工具生成的1536×1024概念场景。原生成文件保留在Codex生成图目录，项目内复制一份。页面明确标注“AI生成场景示意”和“非实拍或检测结果”，没有伪造事件、识别框、在线状态或性能指标。

Vite会将public素材复制到dist/assets，配合已有8000静态资源路由使用；没有新增后端路由或产品依赖。集成时需同时保留public源码素材与dist构建素材。

## 验证

- TypeScript / Vite构建通过。
- 原26项前端测试通过。
- 32项分页浏览器检查通过，覆盖四页切换、侧栏/底栏同步、边界按钮、工作台入口、刷新、直接链接、前进后退和移动端滚动/翻页栏。
- 6种尺寸×4页共24组布局检查，均无横向溢出：1440×900、1280×720、1024×768、768×1024、390×844、320×812。
- 在前三种桌面/横屏尺寸下，四页内容无需内部滚动，翻页栏均在可见区域。小屏允许自然滚动，不以缩小字号强求整页塞入屏幕。
- 既有工作台35项浏览器回归检查通过。

证据位于 `review/revision-2/`。已人工查看桌面概览、核心能力、使用流程与手机概览截图。旧 `review/after`、`review/layout-results.json` 是第一版记录，新增分页以revision-2记录为准。
