# 长视频静止过滤

超过 `LONG_VIDEO_THRESHOLD_SECONDS`（默认 120 秒）的新任务默认启用。先在本地按每秒 1 帧、最长边 320 像素筛查每个窗口，再决定是否按原有配置抽取视觉模型所需的证据帧。不增加云端识别服务或模型依赖。

- 比较相邻采样画面、窗口首帧和上次模型分析后的画面，检测人物活动及物体、背景的像素变化。默认变化幅度达到 18、变化像素占比达到 0.3% 时保留窗口。
- 首个窗口始终分析；变化触发后保留后续约 30 秒窗口，避免遗漏动作收尾。
- 静止时每约 5 分钟调用模型抽查。已观察到人物时改为约 1 分钟；明确的高置信无人观察可恢复普通间隔。
- 先见到人物、之后模型明确观察到无人时，先保留一个“长时间未出现”阈值长度的连续模型跟进期；期间人物重现会结束该跟进。提醒仍需原有的连续无人证据，不能用跳过的窗口补齐。
- 模型输出疑似跌倒、地面躺卧、求助、烟雾、明火或火花后，本任务后续持续调用模型，避免风险持续但画面静止时被过滤。
- 抽查间隔按窗口起点计算，会有最多一个窗口步长的偏差。局部筛查失败、采样不足时保留模型分析，不直接跳过。

这是像素变化筛查，不能确定有没有人物或物体。每秒采样可能遗漏短暂事件，弱变化、小目标、缓慢烟雾和遮挡也可能漏检；光照、屏幕闪烁、摄像机抖动可能增加调用量。周期抽查只能减少静止风险被长期跳过的机会，不能保证发现所有风险。

## 覆盖与恢复

`completed_windows` 表示处理完成的窗口，包含跳过窗口；`activity_filter.model_analyzed_windows` 表示模型分析完成的窗口。`analyzed_ranges` 仅包含模型实际完成的窗口，`skipped_static_ranges` 保存跳过的时间范围及变化比例。跳过不生成模型事件，不充当无人证据，也不能用于拼接跨缺口的长时间未出现提醒。

检查点保留过滤判断、画面参考和人物/风险上下文。暂停后继续不会重复模型已完成的窗口，仍遵守每日调用上限。修改过滤参数会改变任务指纹，需恢复原配置继续或重新分析。旧的未过滤长视频检查点可设置 `ACTIVITY_FILTER_ENABLED=false` 后继续。已完成的旧录像不会自动重新分析或改变证据。

## 配置

`.env.example` 中的 `ACTIVITY_FILTER_*` 提供开关、敏感度、筛查帧率、普通/人物抽查间隔及后续保留时间。修改后重启服务。默认开启，不需要添加 API 配置。

降低像素变化阈值/变化比例、提高筛查帧率、缩短抽查间隔会减少漏检机会，同时增加本地处理或模型调用。关闭过滤后按原流程分析全部窗口。过滤前无法精确预估实际调用量，计划中的窗口总数是无重试时的调用上界，不承诺固定节省比例。

12 小时/24 小时全片速度和风险识别效果尚未实测；验收以实际运行的自动化测试与短片筛查结果为准。
