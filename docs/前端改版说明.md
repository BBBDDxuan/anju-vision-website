# 安居视界前端改版

2026-11-05。官网与视频工作台沿用深海蓝视觉，保留现有后端 API。

## 内容

- 官网三段实景视频可在卡片内独立播放；疑似跌倒案例支持全宽证据面板、2.30–6.30 秒证据区间、真实关键帧和模型复核说明。展开后自动滚动定位。
- 举手与打火机火焰只有实景素材，识别结果仍待接入。
- 视频分析工作台使用左侧播放器、右侧事件 / AI 问答 / 追踪与复核标签，所有功能共享当前录像和任务。
- 保留摄像头、上传、任务暂停继续、问答、物品追踪、人工复核和异常处理；优化桌面与手机布局、标题、间距和暗色空态。

## 构建与测试

```powershell
cd frontend
npm ci
npm run build
npm test
```

`frontend/dist` 按仓库现有约定保留，可供 Python 后端提供页面。开发启动、依赖及模型配置仍见根目录 README。

浏览器测试通过 `npm run test:e2e` 执行，默认使用本机预览 `http://127.0.0.1:5178`；该服务需要指向本分支的前端及本地测试后端。`frontend/playwright.config.ts` 可调整端口和浏览器路径，或通过 `ANJU_BROWSER` 指定 Chrome 可执行文件。真实上传用例会创建并在结束后删除测试录像，其他业务联动使用明确标记的 UI 接口夹具，不发起模型推理。

只验证静态前端时无需模型。真实分析与摄像头仍需要各自服务和硬件配置；浏览器夹具通过不代表模型或硬件已完成端到端验证。

## 素材范围

前端包含官网所需的 3 段演示视频、海报、5 张引用关键帧及公开案例 JSON。`.gitignore` 只对这些固定演示路径放行，上传录像、运行数据、原始模型导出、环境配置、依赖目录和本地备份仍不进入仓库。
