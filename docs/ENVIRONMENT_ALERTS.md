# 安居视界：环境危险事件

2026-10-20。新分析支持烟雾（smoke）、明火/火焰（flame）和火花/电弧（sparks）候选，不需要重新训练模型权重。

## 使用

上传含相关现象的录像并开始分析，或重新分析已有录像；旧结果不会自动补出新事件。点击“事件分类 → 环境危险事件”查看独立红色卡片。人物重要事件仍只包含摔倒、求助、长时间未出现，环境危险不会混入人物或物体分类。

每条卡片提供历史录像时间、主体/位置、推测或观察、依据与限制、证据回看和“标记已知悉”。可以启用浏览器通知，页面打开期间收到新候选时提示；同一提醒在页面内去重。问答可问“视频有没有烟雾？”“什么时候出现明火？”或“有没有火花？”，结果关联实际视频证据。

## 判定与证据

- 使用已有Qwen视觉适配层及v1.4事件提示词，优先提取有依据的危险现象，不新增付费模型调用步骤或改变每日预算。
- 主体为明确的物体或位置，不把人物写作冒烟/起火主体，不猜测起火设备或原因。
- 至少需要两个不同时刻的原片证据；短暂火花允许一次现象与前后背景，不能把背景声称成火花持续存在。
- 区分水蒸气、灰尘、灯光、反光和屏幕内容。明显属于这些非危险来源时不报告环境危险，不能排除危险时保留推测及替代解释。受控炉火也不直接等于火灾。
- 分数低于0.55、未知、无证据或非原片证据不产生提醒。满足展示要求的三类候选均标红；红色表示重点关注，不代表确认火灾或漏电，推测仍是推测。
- 按主体、现象类型与时间分别合并重叠提醒，烟雾、明火和火花不会互相覆盖；原始事件不改写、不删除。

## 边界与验证

当前仍是上传录像的历史分析，没有连接实时摄像头、远程手机推送、独立烟感或电气传感器。检测延迟取决于窗口、模型速度与预算；采样可能漏检短暂火花。此功能不能替代消防探测器或紧急呼救。没有提醒不表示安全。

本轮39项后端定向测试、39项前端规则测试和前端构建通过，浏览器流程使用显式模拟模型、合成视频与模拟Notification接口；无新增付费调用。真实烟雾、火花和明火的检出率、误报率及操作系统实际通知尚未验证。模拟数据不会作为生产分析结果。

证据：`evidence/environment-hazard-tests.xml`、`environment-frontend-tests.xml`、`environment-browser.json`。环境候选仍使用既有`/events`、`/alerts`、`/query`接口、SQLite持久化和删除清理。
