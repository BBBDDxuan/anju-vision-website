# 可编辑设计源与视觉规范

2026-10-18，设计工作稿。它们不代表已完成的模型输出或前端业务功能。

## 封面

- 源文件：`design/cover.svg`，1600×900、16:9；文字、证据卡、连线均为SVG对象，可在浏览器、Inkscape、Figma等工具继续编辑。无需位图生成模型。
- 视觉概念：从清楚的历史观察，经过有条件的关系推断，走向诚实的未知边界。以一条证据链代替“全知监控”视觉暗示。
- 主要文案：“拾迹 Home”“让家拥有记忆，让过去可以被追问。”副标题“Evidence-Grounded Visual Memory”；短标签“观察 / 推断 / 未知”。
- 配色：深墨绿`#102F2C`、暖白`#F5F3EB`、青绿`#71D6B3`、琥珀`#F4B45F`；直接观察用青绿，推断用浅蓝，未知用琥珀，同时保留文字标签，不只依赖颜色。
- 构图：左侧标题与一句价值说明，右侧三个可编辑的证据阶段卡，底部预录制视频说明；外围约80px安全区。
- 比例与格式均为推荐；**未核实官方封面尺寸、容量和PNG/JPEG限制**。若官方要求1:1，重新安排标题与三卡，不把16:9图直接拉伸；暂不增加多版源文件。

## UI

- 源文件：`design/ui-wireframe.html`，无外部网络依赖，浏览器可直接打开。CSS变量与语义HTML可编辑；它是静态布局稿，不会上传或调用模型。
- 页首标“设计稿”，案例卡标“示例”；主区域左侧播放器/时间线，右侧问题与分句证据；unknown必须有文本原因。
- 主要页面保持一屏内清楚看到视频、事件、回答和引用。不要在正常产品界面展示token配置、schema、底层模型堆栈等实现细节；只在高级设置/诊断页提供。
- 产品真实界面应显示“预录制视频”“视频覆盖至…”，服务故障保留可读错误，不使用空白页或假成功动画。
- 字体用系统可用微软雅黑/等宽替代，设计稿无付费字体、外链图片或第三方商标。
