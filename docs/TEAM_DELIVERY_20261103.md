## 队友操作

1. 克隆仓库并安装 Python 3.12+（可另用 Python 3.11 作为检测基础解释器）。
2. 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-team.ps1 -Device cpu`。
3. 按 README 在本机补全两份 `.env`，需要云复核时启用 `VLM_ENABLE_NETWORK=true`。
4. 执行 `start.bat`，浏览器打开终端显示的本机地址，自行导入视频。

首次安装需要网络下载 Python 依赖；下载发生错误时不要忽略退出码或跳过哈希校验。
