# 重复事件整合

时间线默认折叠重复记录，踪迹回溯、问答和人物预警共用事件分组。已保存的视频刷新页面即可使用，无需再次调用模型。

重复匹配要求：同一视频、同一主体 ID、同一动作、同一目标、相同事实/推测类型及核验状态，时间区间重叠且共享原片证据时刻。主体身份有歧义、未知事件、已人工核验记录不自动去重。不会根据相似名字强行合并两个主体。

“出现”可以伴随动作；“跌倒”和“地面躺卧”可以伴随出现，但分别保留为不同动作。“起身”“行走”、相反操作或未知状态等冲突证据会阻止重复匹配。不能只按主体、重叠时间和共享画面把所有动作合成一个动作。

一个重复组需要保留所有成员共同的时间交集和证据时刻，避免仅靠两两关联无限合并。展示时间采用所有来源的最早开始、最晚结束；原始 ID、模型分数、理由和证据均不改写，可以展开逐条查看。不同可信等级的重复记录统一按较谨慎的可见等级展示，推测不会因此升级为事实。

原有的相邻人物行为折叠、多次位置观察仍保留，文案区分相邻采样与重复证据，不保证采样间连续发生。环境危险预警另保留按危险类型独立聚合短间隔持续警情的规则，这不等于删除原始事件。

启动服务时会根据新规则重建派生预警，合并警情保留原有“已知悉”状态，不修改原始分析和核验日志。此规则处理模型已经输出的重复记录，不能保证识别结果本身准确，也不能补回漏检事件。
