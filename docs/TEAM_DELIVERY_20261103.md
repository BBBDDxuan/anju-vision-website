## 队友操作

1. 克隆仓库并安装 Python 3.12+（可另用 Python 3.11 作为检测基础解释器）。
2. 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-team.ps1 -Device cpu`。
3. 按 README 在本机补全两份 `.env`，需要云复核时启用 `VLM_ENABLE_NETWORK=true`。
4. 执行 `start.bat`，浏览器打开终端显示的本机地址，自行导入视频。

首次安装需要网络下载 Python 依赖；下载发生错误时不要忽略退出码或跳过哈希校验。

## GPU 默认推理更新（2026-11-03）

- 安装入口默认改为 CUDA；没有 NVIDIA GPU 时须显式 `-Device cpu`。固定 PyTorch/torchvision 的 `+cu126` 或 `+cpu` 后缀，避免从 CPU 切换到 CUDA 时 pip 继续保留 CPU 包。
- 新配置重建使用检测解释器检查 CUDA；自检让姿态、明火模型执行真实前向并核对参数所在设备，不只看 CUDA 是否可用。
- 本机复用已验证的现有 CUDA 环境，不重新下载大体积 CUDA 包；该本机解释器路径只写在被忽略的 `.env`，不进入仓库。队友仍用安装脚本构建自己的环境。
- 实测 RTX 4060 Laptop GPU、torch 2.13.0+cu126：姿态与明火模型实际设备均为 `cuda:0`，网页健康与状态接口自检通过。
- 使用当前网页配置调用生产扫描：`11月3日 (1).mp4` 完整读取 754 帧，424 次姿态前向，24.9 秒产生一个 `interrupted_inverted_pose_review_v1` 候选；该次扫描墙钟耗时 26.377 秒（包含子进程初始化，不含云复核）。
- 同一张 1920×1080 开发视频帧，同一 CUDA 环境内分别以 CPU/GPU 执行姿态+明火组合推理（含启用的姿态恢复与分块；每种预热 3 次、计时 15 次）：CPU 中位 178.292 ms，GPU 中位 37.204 ms，约 4.79 倍。已同步 GPU 计时；该结果不是网页端到端速度、全视频 CPU/GPU 对比或准确率提升证明。
- 安装/设备配置单测 9 项通过。未改前端、模型权重或识别阈值；未调用云模型、实摄或手机通知。运行中的后端需重启才会重新载入配置，旧视频分析结果需重新分析。
