# 跌倒识别扩大样本修复与最终本地验收

验收日期：2026-11-01。本报告替代早期报告对“修好”的范围解释，保留旧报告和所有历史结果。

## 结论

**本轮针对性修复与本地验证已完成，跌倒识别仍有已知漏检。** 两段最初漏检的视频能产生复核候选；额外9段公开模拟跌倒中，候选覆盖从v1的1/9提高到5/9。5段公开非跌倒反例未产生候选。最终结果来自当前代码重新执行的实际模型推理，不只是缓存回放。

这里的5/9是开发样本上的“产生候选的视频数”，不是准确率，也不是独立测试集召回率。样本来自同一个公开数据集且用于修改规则，不能据此证明跨场景泛化。模拟跌倒不等于真实老人意外跌倒。

## 原因与最终修改

原判据依赖向画面下方的髋部运动、较大的躯干倾角及持续横卧。向镜头前扑、侧倒、后倒时，这些二维投影特征不一定同时成立；下边缘截断及关键点失效还会中断历史。第一版修复找回原始两段视频，但额外9段仅检出1段，说明需要扩大验证。

最终保留YOLO11n-pose和原严格跌倒检测，扩展`ReviewFallDetector`的候选分支：

- 原0.2–0.6秒快速下降分支保留。近期站立参考、髋肩下降、框高度收缩，再结合倾倒或双脚移动，处理前扑和截断。
- 新侧倒分支观察不超过0.8秒的轨迹，联合躯干转动、髋部运动、肩部运动、框高度收缩及躯干竖直跨度缩短。另需双脚关键点可信，并出现“髋部下降且相对脚部横向偏移”或“脚部明显抬起”。
- 原试验仅靠转动和框缩小，会误触发跪下、捡物；增加脚部支撑约束后去除。原demo约77秒弯腰时髋部上移，但脚仍着地；进一步要求髋上移情况下必须有脚部抬起证据，去除这次误触发。
- 补充近似竖直投影的快速下降候选：可靠脚部下，髋部下降与相对脚部的水平偏移同时成立。
- 缺人、关键点失效、跟踪变化、重连、长间隔和倒退清空几何历史；与严格分支共享冷却。新增分支仅由候选收集器启用。

所有新增事件均为`review_required=true`。视频分析和实时摄像头使用同一候选收集器，仍须Qwen多帧复核才可能变成确认报警；没有把这些几何条件升级为直接报警。

本轮没有替换生产权重，也没有启用额外旋转推理。模型推理次数保持原样；本轮没有测试实时摄像头FPS。

## 开源替代模型对照

下载和试验均在G盘，生产仍用原权重：

- `melihuzunoglu/human-fall-detection`的`melih-yolo11-fall.pt`：离线评估11段视频。其`fallen`标签在S7仍站立的0秒已输出0.686分；原demo实际跌倒附近没有相应命中，约80秒下蹲处反而出现大于0.9分的`fallen`帧。因此没有接入生产。帧标签和时间规则候选不构成同一评估口径。
- 官方YOLO11s-pose：在旧v1规则下额外9段覆盖2/9；nano+双向90度旋转在旧v1规则下覆盖4/9。都是隔离试验，不能将这些旧规则结果说成最终代码结果。旋转实验每帧额外两次姿态推理，因此本轮未部署。
- TSSTG骨架动作模型仅检查资料，旧姿态接口和权重/许可问题尚未完成核对，没有集成或声称验收。
