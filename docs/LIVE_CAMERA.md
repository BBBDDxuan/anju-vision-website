# 安居视界：本机实时摄像头

2026-10-29，工作区 `G:/比赛/AI黑客松`。这是原有网页的增量接入，不替代 `elder-safety` 后端/手机通知服务。

## 使用

1. PowerShell 在项目根目录运行：
   ```powershell
   Set-Location 'G:\比赛\AI黑客松'
   .\scripts\start-camera-web.ps1
   ```
2. 浏览器打开 `http://127.0.0.1:8000/workspace`，点击「开启摄像头」。首次加载 GPU 模型需要等待；看到绿色人体框、姿态骨架及「本地实时识别中」后再做测试。
3. 点击「停止预览」停止 GPU 工作进程、RTSP 解码和录像子进程，并封存最后一段录像。离开工作台、关闭所有预览页且没有其他状态轮询客户端后，约 30 秒停止取流。网页服务器本身继续运行，终端 Ctrl+C 停止服务器。
4. 启动器只在当前进程强制关闭录像的云模型分析调用、禁用云部署模式，并将 DATA_DIR 指向当前 G 盘 data；不改父项目 `.env` 或原有预算设置。原先配置仍指向旧 F 盘且旧 venv 不能启动，故使用现有项目 CPU 环境承载网页、独立 G 盘 GPU overlay 承载实时模型。

摄像头取流地址只读取 `G:/比赛/AI黑客松/elder-safety/.env`，禁止把密码粘贴进网页或 URL 地址栏。浏览器收到的仅为本机转发的 JPEG 与统计，不包含 RTSP 凭据。

## 功能和隐私边界

- 页面显示真实摄像头画面、人体框、COCO 关键点骨架、火焰候选框、GPU 推理统计和本次会话候选报警。
- 重用现有本地 YOLO 姿态、火焰模型与时序检测器；不是调用 Qwen 逐帧分析。当前姿态/预览主循环上限 20 FPS，浏览器每 66ms 检查新帧；火焰以独立线程约每 0.2 秒启动一次完整高清扫描。实际速度取决于取流与设备负载，不是准确率结论。
- 网页预览与最近 20 条候选报警保存在内存；另已启用 G 盘本地原始视频录像，无音频、无 AI 检测框、不上传云端。默认每 5 分钟分段，保留不超过 3 天，容量目标不超过 10 GiB，至少保留 5 GiB 磁盘空闲；每分钟清理最旧的已完成系统录像。停止后候选列表保留至下次开启。详细路径、策略及限制见 `elder-safety/docs/camera-recording-20261029.md`。
- API 严格仅允许 loopback 客户端、同源操作；`cloud_mode=True` 拒绝摄像头访问，避免原网页云部署暴露家庭摄像头。不要改为公网/局域网监听来绕过这些限制。
- 实时报警已通过独立事件队列接入通知后端；不接入原录像事件库。手机真实推送和后台常驻监护仍待配置/验证；预览不上传证据。详见 `elder-safety/docs/mobile-notifications.md`。
- 求助仅指约定双臂举高伸展、手离开头部并持续保持；烟雾和电火花/电弧暂不识别。没有报警不代表没有风险。

## 桌面摆放怎么测试

桌面摆放不是直接禁用模型的条件，但尚未对该摆位建立准确率结论。先把摄像头固定在桌边、避开桌面遮挡，保持画面方向正常，让人物头、举高后的双手、躯干、腿和周边地面尽量完整入镜；不要只拍到桌面或坐着的上半身。可侧向拍摄活动区，避免过近、强逆光和运动模糊。

- 求助手势：确认鼻、肩膀、手肘、手腕的骨架点随人移动，再正常站立、双臂向上伸展、手离开头部保持约 2 秒，检查候选提示；不要把单次触发当作准确率。
- 跌倒：当前规则依赖从直立到快速下落的时序和身体倾斜，只见上半身或地面被遮挡不适合验收。只能使用受保护的安全演示或有授权的预录素材，不让老人/测试者真实跌倒。
- 火焰：能看到火焰区域才能测试；本轮画面没有火焰候选，未证明此摆位的识别效果。不要点火；如用屏幕播放合法测试视频，记录为屏幕回放，模型可能把屏幕火焰当候选。

安装视角变更后重做正常走动、坐下、弯腰等干扰测试；不根据一次桌面试验声称真实居家安全效果。
