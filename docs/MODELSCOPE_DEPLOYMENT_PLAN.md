# 安居视界：魔搭创空间部署调研

初始调研日期：2026-10-21。以下保留部署前的方案与判断；后续已创建私有空间并上传部署代码，当前实际状态和验收结果以[部署记录](MODELSCOPE_RUNBOOK.md)为准。

## 推荐方案

采用应用（创空间）的Docker类型，保留React＋FastAPI＋SQLite，将前端构建产物由FastAPI同一服务提供。模型继续通过后端调用已配置的Qwen兼容API，不在创空间运行大模型权重，因此优先选择账号当前可用的免费CPU资源。免费托管不包含第三方Qwen API费用，不保证不限时或永久在线。

平台官方部署指南指出Docker需要阿里云账号绑定及实名认证，服务监听0.0.0.0:7860，密钥通过Secrets管理；具体资源、额度和界面以登录账号后显示为准。

## 用户操作顺序

1. 登录https://modelscope.cn/，完成创建Docker创空间所需的账号绑定与实名认证。
2. 从https://modelscope.cn/studios创建应用创空间，选择Docker；名称建议anju-vision，展示名称安居视界，选择明确标注免费的CPU规格。先准备部署内容，再开放评审访问。
3. 上传专门导出的云端部署目录，或通过空间仓库推送代码。不要直接上传本机完整目录或“含APIKey私用ZIP”。
4. 在空间设置中添加VLM_API_KEY作为Secret；VLM_BASE_URL、VLM_MODEL、预算等作为配置变量。不得把真实密钥写入源码、Dockerfile、镜像层或部署JSON。
5. 构建并启动后查看构建日志、运行日志，验证外部域名健康检查、视频播放、Qwen网络访问、分析、证据问答。
6. 用无痕浏览器及另一台设备检查评委访问方式。确认空间状态、可见性和体验入口正常后，从平台复制实际展示链接填写赛事表单。

链接格式示意：https://modelscope.cn/studios/用户名/anju-vision。该格式不是已经创建的真实空间，不可直接填写示例。

## 当前项目必须做的适配

- 新增Dockerfile、严格白名单.dockerignore及平台要求的部署配置；Linux镜像安装FFmpeg/FFprobe，构建React，安装Python依赖。Windows的D盘解释器和媒体工具路径不能用于云端。
- 以单进程启动：python -m uvicorn backend.main:create_app --factory --host 0.0.0.0 --port 7860。当前任务管理器与SQLite设计需先保持一个worker。
- backend/main.py的TrustedHostMiddleware现在只允许本机域名，需要新增受控的云端域名配置；来源校验需要正确处理平台反向代理与HTTPS，不能一概移除访问检查。
- 当前所有访客会共享录像库，并能删除录像、触发付费分析。公开前需保护内置示例，隔离访客上传，限制分析与删除范围，并控制请求速率和容量；平台免费额度不替代应用限流。
- 演示建议限制上传到60–120秒短片及较小文件，界面应随云端实际限制显示；24小时录像只保留为本机版本能力边界，不在免费云端承诺完整处理。
- DATA_DIR建议配置为/mnt/workspace/anju-data，以利用官方说明的持久化目录。须实际验证重启后的数据库、额度账本、视频和证据保留情况；迁移或重命名空间仍有数据丢失风险。
- 保留MAX_MODEL_CALLS_PER_DAY=60、手动暂停、有限重试；云端额度不足时清楚显示暂停。发布前实测从云端访问用户实际API服务，不能仅因本机可调用就视为云端已验证。
- 内置少量许可允许展示的CAUCAFall样本与已保存真实Qwen分析，保留来源、许可和“已保存分析”说明；不带入私人居家录像、本机数据库、受限数据集或私用压缩包。示例回放不调用模型，新分析才调用模型。
