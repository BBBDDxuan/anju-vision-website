# 家庭账号与全员告警

本地启动入口启用家庭账号模式，一台后端对应一个家庭。首次在后端电脑本机网页创建管理员，之后从右上角头像进入「家庭管理」并生成一次性邀请。其他家人用 App 扫码注册自己的账号；邀请码不授予管理员权限。

- **注册家庭成员**是可登录的家庭账号。所有有效账号都能查看其家庭的注册成员目录；普通成员只能看到显示名称和角色，不能查看别人的登录名、会话或凭据。管理员可停用普通账号并撤销其会话。
- **被监护人员**是共享档案和人脸识别对象，不需要注册。网页的被监护人员管理和 App 的成员监护页与注册账号目录分别显示。
- 所有有效账号共享同一告警记录和处理状态。账号版不区分主要/备用联系人；App 前台按账号分别提示新确认告警，不因另一人先确认而取消。首次同步历史不弹提醒。账号版未启用后台或锁屏云推送。
- 旧数据库中的联系人字段和旧版通知策略保留用于兼容，但账号接口不再选择或返回主备角色。旧网关令牌在账号模式下只可用于受校验的 APK 升级接口，不能读取家庭业务。
- 正式手机登录需要 HTTPS。用手机信任的证书启动手机网关；局域网自建 CA 配置和服务器私钥只保存在部署机上，不进 Git。App 构建可按自身仓库说明选用该部署的公开 CA 与私有地址列表，不能跳过证书校验。
- 账户库保存在实际 DATA_DIR 下的 accounts.sqlite3；迁移前停止服务并备份业务数据和运行配置。换电脑后恢复账号库，可用原账号登录。

前端构建产物由后端提供。新的注册成员接口需部署相匹配的后端版本；仅下载 APK 不会升级电脑后端。
