# 实验、拍摄与验收方案

状态2026-10-18：基础环境和合成视频处理检查已执行；**以下产品/模型测试全部未执行，没有准确率结果。** 记录模板为`evaluation/results_template.csv`，应保留原始输出和证据。

## 数据：先小且真实

- B拍8段固定机位真实视频，每段30–60秒。3段开发（D01–D03，12问题）用于调抽帧/提示；5段保留（H01–H05，20问题）用于最终固定版本评估。每段4个问题，尽量2个可由当前视频回答、2个无法确定或需要边界说明，总计32问。
- 至少覆盖：放桌面→拿起→放包、包移动/离开、包中途取出、关键动作在镜头外、遮挡、同类两包、不同动作顺序。片段可重拍但不能只保留成功样本；保持失败及原因记录。
- 最终演示可选最清晰开发片，但不纳入未见保留集成绩。不要把Ego4D第一人称指标与固定摄像头小样本混比。
- 拍摄清晰可见的真实动作，动作间停顿1–2秒以观察稀疏采样极限；另拍快速动作压力样本，承认清晰版和压力版不同。不要用合成编码探针当摄像头视频。
- 不拍无关人员、真实家庭私密内容；由D保留出镜与素材使用确认，不放入公开代码包。用本人/队员道具和摆拍视频，提交时注明演示为真实摄像头拍摄的预录制场景。

人工gold由B建立、另一人复核：video_hash、实体/同类身份、每个动作start/end、支持问题的证据窗集合、在截止时刻是否可回答、未知原因。含糊样本gold也必须标ambiguous，不能强定真值。模型请求不含gold或预期答案。

## 必做核心测试

| ID | 输入/操作 | 期望（尚未执行） | 重点核对 |
|---|---|---|---|
| T01 | 可见放置、拿起、移动 | 事件主体、动作与证据时间匹配 | 不用只看文字描述“像不像” |
| T02 | 问最后一次看见的位置 | 返回最后直接证据，不拿旧事件当最新 | event和frame属于同video |
| T03 | 包清楚离开画面 | 当前具体位置unknown；可回最后观察历史 | 不断言钥匙当前在沙发或已知镜头外地点 |
| T04 | 放包动作未拍到 | 不得创建确定put_in；说明缺少关键动作 | 前后状态变化不等于直接看到中间动作 |
| T05 | 改为放入→取出→包移动；另以乱序JSON输入 | 按视频时间取出结束in关系；乱序同时间重放结果一致 | 相互重叠时间有歧义则不强排；重复导入不重复事件 |
| T06 | API连接失败、超时、401/429/5xx、非JSON/缺字段 | 可理解错误与重试入口；无密钥堆栈；失败窗不标成功 | 注入错误与真实服务故障分开记录 |
| T07 | 两个相似黑包交错、遮挡后重现 | 身份不充分时ambiguous，询问对象 | 不因为同色同类就强行合并 |
| T08 | 仅遮挡或检测不到，没有过画面边界 | occluded/not_observed，不能标explicit_exit | 规则测试与视觉漏检分开 |
| T09 | 未完成分析/跳帧缺口后问当前 | 说明覆盖不足，允许partial而不装作全量 | 完成百分比不掩盖失败窗口 |
| T10 | 引用伪造ID、跨视频帧、超出片长时间、循环容器边 | 拒绝写入/推断，返回校验问题 | 这是语义校验，不仅JSON能解析 |
| T11 | 重启应用，重复上传，同版本缓存，再换模型/提示版本 | 持久化恢复；缓存注明来源；不同配置重算 | 不把人工fixture标真实分析 |
| T12 | 损坏MP4、VFR/旋转视频、超大文件、路径穿越名 | 支持的正确处理，不支持的明确说明 | PTS/seek是否与原片对齐；媒体Range播放 |
| T13 | 未预置视频和同义问题 | 现场实际分析并给相关证据 | 排除按文件名、hash或固定问句返回预写答案 |
| T14 | 可回答问题与大量unknown问题混合 | 可答问题正常答，缺证据问题拒答 | 不能全部拒答伪装可靠 |

## 指标定义与记录

| 指标 | 计算方法 | 用途 |
|---|---|---|
| 事件precision/recall/F1 | 同一主体身份、动作相符且时间IoU≥0.3做一对一匹配，precision=TP/(TP+FP)，recall=TP/(TP+FN) | 明确漏动作与错动作，阈值为本项目预设 |
| 最后观察准确率 | 正确主体、关系、最后观察证据均正确的问题数 / 此类可答问题数 | 区分旧证据和最新证据 |
| 引用有效率 | ID真实且属于本视频、时间合法的引用数/全部引用数 | 只衡量引用合法，不保证内容支持 |
| 证据支持率 | 由人工检查证据确实支持的事实/推断分句数 / 全部带结论分句数 | 推断须包括条件和全部前提证据 |
| 错误确定断言率 | 在gold不可确定问题中仍断言确定当前位置的问题数 / gold不可确定问题数 | 核心安全边界；越低越好 |
| 拒答召回 | 正确标unknown/ambiguous的问题数 / gold不可确定问题数 | 不能单独报告，防止全拒答 |
| 可回答覆盖率 | gold可答问题中提供有效答复的问题数 / gold可答问题数 | 拒答的代价 |
| 风险与覆盖 | 错误实质答复数/全部实质答复数；全部实质答复数/全部问题数 | 拒答与部分答复的口径事先固定；分母为0记N/A |
| 时间证据 | 时间IoU；多步链的所需证据窗召回率 | 不能用只命中一个窗代替整链支持 |
| 性能/费用 | 处理时长、查询时长、真实usage/计费单价与时间、frame引用数、调用数、重试数 | 小样本报告中位数/范围/原始n，不用单次伪称p95 |

partial回答按分句评判；“最后看到在包内，但现在不确定”不是整题拒答，同时记录已答历史和未答当前。纯空话不算有效覆盖。未知问题没有支持实体位置的证据时可给“未找到可用证据”，不伪造引用。

## 对照实验：隔离规则与感知

1. **主对照**：同一模型、同一视频与4问题。Baseline直接看有序采样帧回答；Proposed分窗抽事件+规则+引用。每视频各自总帧引用≤128、总调用≤12、总输出token上限8192。记录实际预算差异，不把同一上限称完全相同计算量。两路看到的独立帧集合尽量相同；若补帧不同，另列该实验不归因为规则收益。
2. **推理消融**：固定同一份事件，不再调用视觉模型；比较只取最后实体事件与加容器/失效/未知规则。用人工事件fixture验证规则逻辑，与真实模型事件测试分栏。前者不证明感知识别正确。
3. 先用3段开发集做决策，冻结后仅一次最终评估5段保留集。若修复后复测，保留旧结果、标出版本及已经看过的测试集，不能重新称未见。
4. 预算不足先完成6类安全测试与事件质量记录，延后完整Baseline实验；必须写“未完成对照”，不能改用主观体验声称技术提升。

首日继续开发建议门槛：关键动作事件P/R各≥0.8，6类固定反例没有错误确定当前位置，可答正确覆盖≥80%；这些是工程门槛，未达成也不得隐去。最终报告给所有分母、样本条件和失败片段，不做统计显著性或泛化保证。
