# 提高坐姿跌倒候选召回（2026-11-06）

已接入正式公共检测器。此前遗漏的 CAUCAFall `S02_Fall_sitting` 和 `S04_Fall_sitting` 现在会送审；四段原视频经正式扫描方法重跑，与缓存回放的候选时间和元数据完全一致。没有训练或更换 YOLO11s 权重。

## 改了什么

在现有坐姿/起身分支中增加肩髋下降候选。已有稳定坐姿背景后，跟踪起身最高髋位，若连续三个可靠肩髋观测、跨度至少 0.2 秒，相对参考人物框高度的肩下降至少 0.15、髋下降至少 0.08，就允许提出视觉复核候选。

这条候选不要求脚点可靠、腿伸直、标准横躺或倒置，也不再要求先通过快速下降速度门槛。仍沿用肩髋置信度、人物跟踪连续性、重叠歧义排除、2.5 秒参考窗口和共享冷却。缺失采样会清空连续观测，不补造关节或插值。该分支只在复核候选模式启用，独立严格告警引擎未修改。

算法标识 `seated_core_descent_review_v1`；策略版本 `fall-recovery-v5`。候选元数据明确写明需要复核、不证明跌倒或触地，正常坐下、跪下和主动降低身体也可能匹配。
