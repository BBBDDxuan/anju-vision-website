# 场景标定与事件复核交付记录

> 以下为 2026-10-18 的历史交付记录。2026-10-19 后未复核关键动作改为单列候选推测，支持模型上下文解释；当前行为与验证见 [上下文推测更新](CONTEXT_INFERENCE_UPDATE.md)。

2026-10-18，在现有 FastAPI、SQLite、React 和 Qwen 适配器上实现，未增加向量库、图数据库、训练框架或账号功能。

## 本轮行为

- 每视频保存归一化矩形位置标定；名称和几何含义不可覆盖历史 ID，删除后重建新的区域。
- SQLite 新增追加式 review_log，保存区域版本、AI 开始/结果/失败、人工确认/否定/未知/纠正/撤销。原 memories/events 数据保持为模型原始候选，读取时组合复核覆盖层，状态缓存同步重算。
- 放入、取出、离开画面的真实模型候选，未获复核支持前降为未知，不参与问答和容器关系推断。明确测试 Mock 保留原有测试流程，不作为真实效果证明。
- 人工可改动作、位置、证据帧，时间由所选真实帧生成；拒绝跨视频/未定义帧、自己指向自己、关系动作缺目标、过期版本与并发覆盖。
- 人工确认与机器支持明确区分；机器复核不会写 human_reviewed。重新分析的不同 run_id 不继承旧事件纠正。
- AI复核为一次用户触发的一次请求：局部2fps、最多12秒，后续片尾最多3帧，合计最多32帧。可额外提供用户框定区域的两张细节图；保留实际解码 PTS、原始帧和请求响应。
- 关键动作的机器支持至少需三个不同时间的直接过程/完成证据；不符合时降为未知。该门槛不能自动证明视觉事实正确。
- 对位置事件，可将模型物品框唯一匹配至人工标定区域；有歧义时不强行指定。该功能不等于3D定位或高级物品追踪。
- 通用中英文类别别名改善中文检索，物品 ID 不合并；同类多物品依然消歧。原始模型标签保留在别名和原始记录中。
- React 接入区域拖拽、复核状态、源帧/物品框、证据选择、人工纠正、撤销、日志和问答更新。
