# 事件置信分级与简化界面

更新：2026-10-20。本轮按用户要求移除前端人工复核入口，改为绿色/黄色分级，隐藏很低可信事件。

## 使用

刷新工作台即可看到变化，无需重新分析。事件时间线有 **全部、较高可信、谨慎参考** 三个筛选；绿色表示较高可信，黄色表示谨慎参考。点击时间引用继续回看原片。

重复记录仍可折叠，但只会合并相同颜色的可见成员。**展开全部可见事件** 不会显示低可信记录。颜色说明位于时间线顶部。

原人工复核面板、逐条核对按钮、区域标定、确认/纠正、AI复核与上下文复核按钮均不在当前界面呈现。已有历史记录保留，不删除、不自动更改。

## 分级规则

模型的 `model_score` 是未经校准的自评分，颜色是展示规则，**不能解释成真实正确率**，也不会把缺失分数补成数值。

| 条件 | 展示 |
|---|---|
| 分数≥0.75，属于直接观察，有有效原片证据、实体无歧义且没有不确定理由 | 绿色：较高可信 |
| 0.55≤分数<0.75，并有证据 | 黄色：谨慎参考 |
| 分数缺失，属于直接观察，有至少两个相隔1秒的有效原片时刻，实体无歧义且没有不确定理由 | 绿色；明确标注未提供模型分数、按证据分级 |
| 分数缺失，有效证据未满足上述条件 | 黄色；说明模型未提供分数 |
| 上下文推测、身份有歧义、带不确定理由 | 最多黄色，即使分数很高 |
| 非位置观察的动作只有单时刻证据 | 最多黄色 |
| 分数<0.55、未知事件、证据/实体引用无效、非原始帧证据 | 隐藏 |
| 入包、取出、出画缺少两个实际时刻，或推测缺理由/两个时刻 | 隐藏 |

后端原有证据规则继续生效：仍被判为推测的关键动作，不会只因高自评分而升绿。本轮没有改变提示词、模型、JSON Schema或模型权重，没有为旧结果补造分数。

绿色分数门槛已从0.85下调到0.75，隐藏门槛仍为0.55。证据分级只适用于缺少分数的直接观察，不覆盖已有低分，不把推测或条件关系升级为事实；重复引用同一帧、同一时刻或时间间隔不足1秒不满足升绿条件。

## 全流程一致性

- 时间线、LifeReplay、问答、自动建议均应用相同等级规则。
- 隐藏成员从折叠组中移除；不同颜色分开，缺失/隐藏成员会打断组，避免把前后观察连成连续状态。
- 物品仅由隐藏记录支撑时，不会出现在自动建议和回放对象列表。
- 历史问答的一组来源若部分隐藏，会用剩余来源重建文字、时刻与引用，不沿用被过滤部分的描述或帧。
- 最后出现问题若命中的最新来源低可信，界面显示证据不足，不拿更早的高分事件冒充最新位置。
- 条件关系必须所有来源可见，且最高为黄色。推测仍标注“可能发生”，不升级为事实。
- 后台原始事件和证据完整保留；本轮是前端展示筛选，原始数据API仍可用于追溯。
