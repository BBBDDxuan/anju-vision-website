# 介绍页与录像删除

更新：2026-10-20。

## 打开网页

- 首页：<http://127.0.0.1:8000/>，介绍产品用途、使用流程和接入计划。
- 点击 **打开记忆工作台** 或左侧 **记忆工作台** 进入功能界面。
- 工作台可直接访问 <http://127.0.0.1:8000/workspace>，刷新、浏览器前进/后退正常。
- 左侧 **产品介绍** 和品牌标志可以返回首页。已有 `/?video=...` 链接仍直接进入相应录像，并更新为 `/workspace?video=...`。
- 手机布局保留介绍页导航、工作台入口和录像库抽屉。摄像头、远程手机连接及原生 App 为后续计划。

## 删除录像

两个入口：录像库条目右侧的垃圾桶图标；播放器上方“当前视频”旁的 **删除视频**。

确认框显示名称与影响范围。**取消** 或 Esc 不删除；**确认删除** 后无法在网页撤销。提交时禁止重复提交和关闭确认框。

删除该录像条目、所有分析版本、事件、证据帧、人工复核与标定，以及它独有的托管上传、分析缓存和复核文件。其他录像仍需使用的共享原片保留；删除最后一个使用者时可清理对应孤立托管原片。项目外素材、其他录像和已另存备份不删除。

已发生的请求和费用计数保留，不能通过删除重置日额度。分析、复核或取证中的录像禁止删除；未完成但处于空闲状态的录像可以删除。

删除当前录像后清空播放器、选择、事件和问答；删除其他录像时保留当前选择。普通文件移动失败会恢复原位，保留数据库记录并提示重试。

## 实现边界

- `DELETE /api/videos/{video_id}` 在分析/复核锁和数据库事务内检查状态。
- 只操作已核对绝对路径的 `DATA_DIR/videos`、`runs`、`reviews` 下目录，拒绝路径穿越和目录链接越界。
- 独占目录先在同一数据目录内暂存；数据库提交或文件移动失败时恢复，成功后清理暂存目录。
- 暂存清理失败时返回 `cleanup_pending=true`，网页提示部分文件未清理，残留位于私有 `DATA_DIR/.trash`。本轮没有自动重试清理或回收站恢复界面。
- 这不是安全擦除工具，历史备份由用户管理。异常断电未做故障注入测试。
- 修正播放器和复核面板的重复 React key，切换/删除后不再遗留旧播放器节点。
