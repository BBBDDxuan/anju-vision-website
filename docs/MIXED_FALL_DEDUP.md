# 同一次跌倒的观察与推测合并

同一匿名人物的fall记录，在时间具有实际重叠、共享原片采样时刻、已知位置不冲突的条件下，可合并为同一次候选事件。允许一条缺少位置参照而另一条提供位置；不要求观察/推测标签或视觉推测规则一致。原始事件及其标签、置信度、证据和限制均保留。

时间线默认折叠为一条，混合来源明确标注“模型观察与上下文推测”，按组内较谨慎的等级显示。展开记录可逐条回看。踪迹回溯、网页预警与记录问答使用同一事件边界；混合来源不会把推测升级为观察。

不同人物、明确不同的位置、人工核验边界、未知片段、起身/行走等恢复动作、无共同证据或仅接触的时间端点均不能按此规则合并。所有成员还须具有共同重叠区间与共同证据，避免沿相邻记录无限串联合并多次事故。此变更仅针对人物fall事件；物体及环境事件原有规则保留。

本轮使用本地已有真实分析记录验证2.75–3.5秒的观察和3.0–3.75秒的推测：合为2.75–3.75秒的一组，保留两条来源；派生跌倒预警一条，本地问答一条。未新增模型调用，未重新分析视频。114项相关测试通过；这仅验证去重行为，不代表验证跌倒识别准确率。

本轮只更新本地，尚未同步云端。刷新网页即可使用；如果点击“展开全部可见事件”，会有意展示各条原始记录，可点击“折叠重复记录”恢复合并展示。
