# 局域网快捷连接

账号版可用 `start.bat` 启动，由管理员在本机网页搜索或手动连接摄像头。邀请注册、电脑地址二维码和家庭成员请见 [家庭账号与全员告警](FAMILY_ACCOUNTS.md)。下文为旧共享令牌模式的配对说明；摄像头搜索的操作仍适用。

1. 在电脑上用 `start-phone.ps1 -Address <当前 Wi-Fi IPv4>` 启动。用同一台电脑打开 http://127.0.0.1:8000/，进入「实时摄像头」。
2. 点击浅绿色的「扫码连接手机」按钮，生成二维码。手机 App 打开「我的 → 连接设置」，点击「扫描电脑配对二维码」。扫码成功后确认联系人角色并保存。二维码两分钟过期、只可使用一次，重新生成会使旧码失效。
3. 网页点击浅绿色的「搜索摄像头」按钮，或在 App 摄像头页点击「搜索摄像头」。选择设备后填写摄像头本地密码；用户名、端口和视频路径可修改。连接时由电脑后端验证实际 RTSP 视频轨道，再开启监护。
4. 若搜不到，检查摄像头是否开启 ONVIF / 设备发现、是否处于同一可互通局域网；仍可手填 IP。搜索只获取设备响应的 IP，端口和路径默认使用 554 / stream1，并不代表该型号的实际设置。部分设备需要手改为其专用取流参数。

配对复用现有局域网访问令牌，二维码不含令牌。当前手机网关使用局域网 HTTP，只在可信网络使用，不要做公网端口映射；配对码和令牌在网络传输中不具备 TLS 加密。旧共享令牌模式的手机手动连接和扫码配对由手机网关提供。
