# 网页美化设计与范围

基线：2026-11-01 23:38 交接包。原包保留，本目录为独立开发副本。

## 设计方向

家庭照护者需要先找到当前画面、理解设备是否工作，再回看事件证据。使用深色导航作为稳定的定位区，白色内容区承担画面和证据；报警颜色只用于真实状态。保持中文主导、左对齐和清晰的按钮名称。

核心颜色：背景 `#F3F6F5`、面板 `#FFFFFF`、正文 `#173C38`、主操作 `#176B58`、关注 `#98641E`、错误 `#B6473D`。

字体：优先使用本机 Microsoft YaHei、PingFang SC，西文后备 Segoe UI；不请求外部字体。正文 14px，辅助信息至少 12px，移动端输入 16px。数字使用等宽数字。

桌面结构：

```text
导航 / 录像库 | 面包屑                       服务状态
              工作台标题                 导入录像
              相机 / 录像回放 / 证据问答快捷导航
              16:9 相机画面      实时状态
              会话事件           关键指标
              检测详情 / 录像与存储（折叠）
              录像安全结果 / 时间线 | 证据问答
```

小屏结构：导航抽屉、单列内容、原比例画面、紧凑指标、底部快捷导航。320–1440px 均需检查，平板同时覆盖横竖屏。

## 对照任务的取舍

- 保留既有 16:9、会话事件位置、两个详情折叠，不再添加无关装饰或固定免责声明。
- 让主操作、实际错误与候选复核状态比介绍性文字更显眼。
- 不迁移框架、不改 API / 后端 / 模型规则 / 轮询频率；不配置真实相机或调用付费分析。
- 请求失败后保留停止操作入口，但旧画面与旧指标不能作为当前在线状态展示。
- 测试模拟状态仅在浏览器拦截请求中使用，截图及记录注明模拟；不写入产品数据。

## 验证

修改前已通过现有 24 项 node 测试和 TypeScript/Vite 构建。实际空数据后端在 8000 启动；本机 Python 依赖通过 system-site-packages 复用，并在独立 .venv 补充 python-multipart。它不是一套全新安装且完全符合锁文件的后端环境。

浏览器工具、缓存和运行数据放在 runtime / .venv，不作为交付依赖。
