## 修改与边界

1. 每窗口输出上限2048→4096，请求超时45→90秒。此举减少输出截断/过早超时，不承诺模型服务变快。每批输出总预算保持原值；因此达到总预算后正常暂停，使用继续分析。
2. 基础事件提示词仍为v0.9，保持已有断点兼容。仅失败窗口恢复附加简洁的v1.0恢复约束，记录实际组合提示词的版本和SHA256。
3. 本地格式修复仅处理无损字段别名、单帧列表化和由后台真实PTS替代的模型时间元数据。不补造缺失动作/主体，不完成被截断JSON，不用文字描述猜动作，原始响应保留。
4. 恢复仍遇截断/格式错误时，30秒窗口可拆为前20秒与从第18秒起的余段，保留重叠；成功子片段缓存和断点落盘。最多拆一次，避免无限拆分。所有实际请求计入预算。本次5个窗口均在整窗恢复时成功，真实样本没有触发拆分；拆分跨批续跑由明确标注的Mock测试验证。
5. 新增可选 `/resume?max_calls=N`，用于限定本批实际尝试次数，不改变模型全局预算。
6. 人工界面新增免费取证、审查计数、下一条未审查事件和清空已选帧。免费取证按播放器时刻前后约3秒、2fps抽原片，实际PTS入证据记录，不调用模型、不写人工结论。
7. 人工确认仍确认原主张与原证据；采用新增证据需保存人工纠正。计数包括确认、纠正、否定和无法确定，不能等同于全部确认发生。

此前界面修复同时保留：去掉数据盘/历史回放提示，橙色候选标签恢复正常文档布局。真实30秒窗口本地抽帧从29.766秒降至4.638秒，15帧字节和PTS一致；这只是该窗口的抽帧计时，不是整片推理提速。模型网络处理仍可能占主要耗时。14个窗口由这段片长及30秒窗口/28秒步长计算，其他片长不固定为14个。
