# 重复事件整理与证据保留

更新：2026-10-19。默认折叠重复记录，原始事件与人工复核继续逐条保留。不需要重新识别录像。

## 如何使用

1. 刷新 <http://127.0.0.1:8000/>，选择已有录像。时间线显示“当前显示 N 项 · 对应 M 条原始记录”。顶部事件总数仍按原始记录计算。
2. 相同位置的重复观察显示为“多次看见”，注明采样次数，**不表示期间始终在场**。
3. 点击 **展开 N 条原始记录**，查看每次的具体时间、主张、原始证据与限制。点击时间引用定位原片。
4. 点击某条来源的 **人工核对此条**，自动展开复核面板并选中对应原事件。确认、纠正、否定或无法确定只作用于这一条，没有批量自动确认。
5. 要浏览全部来源，点击 **展开全部原始事件**；点击 **折叠重复记录** 恢复简洁视图。搜索、类型/小时筛选与分页继续可用，筛选只裁剪组内成员，不跨越被隐藏的未知/动作事件重新合组。
6. 问“物品的经过是什么？”时，重复采样观察也会整理成一条带多份引用的描述。问“最后在哪里出现？”时继续返回准确的最后一次原始事件及其证据。

## 本地合并规则

- 只按相同实体ID、目标、动作、观察/推测类型、规则版本和复核状态匹配，不按名称或颜色合并物体。
- 普通观察仅折叠 `seen_at`。相邻采样区间间隔不超过60秒，且间隙须在已处理覆盖范围内。这个阈值用于展示分组，不是物品静止或身份连续的证明。
- 同一物品出现拿起、放下、移动、遮挡、未知、位置变化或推测等其他记录时，观察分组中断。目标物发生动作/不确定变化时，其相关观察也会中断。
- 重叠动作候选须起止时间均相差不超过2秒、区间重叠，并共享真实证据帧时间。仅时间接近不会合并；链式接近不能无限扩展分组。组内仍标为候选，而非自动确认同一次实际动作。
- 人工复核事件和身份有歧义的实体不自动合组。不同实体ID即使同名也独立，避免把两部手机当成一部。
- 来源事件ID和全部证据引用保留。已保存记忆不做迁移或覆盖；新分析也保留原始重叠候选，改变此前直接跳过重复候选的行为。
- 原始模型响应、分析断点和复核日志不改写。人工复核计数仍按原始候选计算，折叠数量不是需审查事件数量。

本轮使用确定性本地规则，没有新增视觉或文本模型请求。文本模型可在后续辅助判断语义近似，但仍需通过上述身份、时间、证据与人工状态边界校验；当前未实现文本模型整理按钮，不会后台自动产生相关费用。

## 限制

归为一组不证明视觉识别准确，也不证明间隙内一直在原处。保守规则可能保留部分重复候选；证据不同、身份不明或人工已复核时尤其如此。LifeReplay保留逐条经历与条件关系，本轮只整理全部事件时间线和问答描述。没有新增完整24小时实测；冻结赛事ZIP仍是旧版本。
