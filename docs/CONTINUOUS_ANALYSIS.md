# 自动接续与手动暂停（2026-10-20）

点击「开始 AI 分析」或「继续分析」后，后端会按窗口持续处理。每批的请求数、帧数或输出预留额度耗尽时，保存检查点、重置本批计数，直接进入下一批。无需反复点击继续；关闭浏览器页面后也会继续，前提是本机后端服务仍运行且电脑没有休眠。

点击「暂停分析」后，按钮显示「正在保存并暂停…」。正在执行的抽帧或模型请求会先结束，保存有效结果，再停止后续处理。不会中途取消已发出的付费请求。稍后点击「继续分析」，复用成功窗口和证据；如果最后一个窗口恰好完成，则直接显示分析完成。

每日请求上限保持不变，本机配置为48次；失败与重试仍计入真实请求账本，自动跨批不会清空每日记录。达到上限时保存并暂停，不会自动等待到次日再调用；次日点击继续即可。金额模式下原有视频及每日费用限制也保留。服务限流、超时和其他错误不会作为正常批次结束无限接续，原有有限重试规则保留。

本次没有提高任何预算配置，也没有重新分析已有真实录像。24小时视频仍未做全长实测。

## 接口

- `POST /api/videos/{id}/analyze`：默认自动接续。
- `POST /api/videos/{id}/resume`：默认从检查点恢复并自动接续。
- `POST /api/videos/{id}/pause`：请求安全暂停，返回202。已暂停任务重复调用保持暂停；没有运行任务时返回409。
- `GET /api/jobs/{id}`：返回`pause_requested`、`pause_reason`、`auto_continue`、累计`batch`和原有进度字段。
- 分析和恢复接口可传`?auto_continue=false`，保留单批运行方式。
- 恢复接口显式传`?max_calls=N`时，只运行最多N次请求，禁用自动跨批，避免绕过调用方指定的次数限制。

`pause_reason=manual`为手动暂停，`daily_limit`为达到请求限额，`batch_limit`为显式单批模式的额度耗尽，其余停止原因见`error`。服务重启不自动调用模型；已有检查点可在配置和提示词一致时继续。
