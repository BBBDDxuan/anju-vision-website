## 处理链路

YOLO 姿态 → 时序候选 → 带时间戳的多张图片 → Qwen 复核。候选覆盖快速倒下、画面边缘/姿态异常时的受限恢复、坐姿滑落、起身途中失稳、前倾跌倒和缓慢下降。规则位于 `elder-safety/ai-service/ai_service/review_recovery.py`；离线扫描和摄像头通过公共 `SafetyCandidateCollector` 使用它。

缓慢下降候选保留最多六秒前情，合计最多十二张真实图片；普通候选仍使用原有较短窗口。Qwen 提示词要求排除正常蹲坐、弯腰和主动躺床/沙发，证据不足则返回 uncertain。此处仍发送多帧图片，未切换为视频输入。

模型分数是姿态质量分数，不是已校准的跌倒概率。候选并不直接等同已确认报警；规则不能诊断头晕，也不能单靠姿态保证区分主动躺卧与失稳。独立运行的严格检测器默认不启用这些复核候选。
