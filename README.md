# 安居视界 · 网页前端

独居关怀与家庭安全网页，基于 React 19、TypeScript 和 Vite。
本仓库包含截至 2026-11-03 的最新前端源码、静态资源、测试与构建产物。

## 页面与功能

- 产品介绍：产品概览、核心能力、使用流程三页。
- 核心能力：人物异常、家庭危险、物品追踪；下方独立展示视频证据回溯。
- 实时摄像头：16:9 预览、实时状态、会话事件及检测/录像详情。
- 摄像头预览：状态保活与画面请求独立，按 20 FPS 预算刷新；请求超时后自动重试，实际帧率取决于设备和后端。
- 导入视频：在空白视频区点击或拖入 MP4，导入后回放并选择分析任务。
- 视频证据：事件时间线、原片回放、关键帧和基于已有记录的问答。
- 侧栏二级项、手机布局与数量显示均包含最新调整。
- 首页场景：老人失衡与地面水洼主图、右上角疑似明火小图，以及人物和物品的功能示意标注。

本仓库只包含前端。录像、分析结果、摄像头与模型调用由原项目的后端提供。

## 本地开发

安装当前受支持的 Node.js LTS 版本，在仓库根目录运行：

```powershell
npm ci
npm run dev
```

打开终端显示的开发地址，通常为 http://127.0.0.1:5173/ 。
`vite.config.ts` 将 `/api` 和 `/media` 请求代理到 http://127.0.0.1:8000 。
使用完整功能前，需另行启动原项目后端。

后端未启动时可以查看产品介绍，工作台会显示接口读取失败；不会产生真实识别结果。
摄像头使用原项目的本机环境和配置，云端分析使用后端配置的模型服务。

## 构建和测试

```powershell
npm run build
node --test tests/*.test.mjs
```

构建输出在 `dist/`。该目录已提交，方便直接交给原项目集成。
本次上传前已通过 TypeScript/Vite 构建和 31 项前端测试。

`npm run preview` 用于检查静态构建，不包含开发服务器的 API 代理，不能替代原后端。

## 集成到原项目

本仓库根目录对应原项目中的 `frontend/` 目录：

1. 先备份原项目前端。
2. 将 `src/`、`public/`、`tests/` 和根目录前端配置文件合并到原项目的 `frontend/`。
3. 用本仓库的整个 `dist/` 替换原项目的 `frontend/dist/`，避免旧资源残留。
4. 启动原项目后端，访问 http://127.0.0.1:8000/ 。

集成时保留原项目自己的后端、模型配置、密钥和数据目录。
此网页需要服务提供静态资源与路由回退，不通过双击 `dist/index.html` 运行。

## 目录

```text

public/            静态图片资源
tests/             前端组件与行为测试
dist/              最新构建，可由原后端直接提供
package.json       开发与构建命令
package-lock.json  依赖版本锁文件
vite.config.ts     Vite 与开发 API 代理配置
```
