# 短暂火光漏检修复与关怀安全界面更新

日期：2026-10-21。当前源码已更新并在本机8000端口运行；2026-10-20的ZIP是此前快照，本次没有重新打包。

## 原因与修改

- 原采样1帧/秒，第一次火焰约在1.2–1.9秒出现，整数秒采样错过。默认对不超过120秒的视频采用4帧/秒、4秒窗口、3秒步长，保留真实源帧时间戳；本例抽取40帧、分析3窗。
- 提示词升级为event-v1.5，明确区分出现、熄灭、再次点燃；只按实际画面生成事件，不预设次数，不把受控打火机等同于家庭火灾。
- 火焰/火花预警不再跨间隔合并，防止两次独立点火被2秒容差合并。实际时间重叠的候选仍可汇总；烟雾仍保留2秒短间隔策略。
- 预警证据展示全部引用帧，滚动查看，避免首尾背景掩盖中间火光。
- 修复“视频中什么时候有人跌倒？”等全局人物行为问答的路由；显式选择不存在的人物时仍返回证据不足。

## 界面与验证

首页以独居老人关怀和家庭危险识别为主，替换桌面物品插画，突出人物异常、烟雾/明火与原片证据。物品查找保留为辅助介绍及“物体事件”入口。示意插画明确标注，不冒充检测结果。

工作台默认进入“安全概览”，人物分类默认重要事件；提醒卡汇总人物重要事件、环境危险线索及已知悉数量。复杂依据与通知说明折叠展示，重要证据和知悉操作直接可用。问答入口优先提供跌倒、明火和求助问题。

相关测试记录：`evidence/safety-density-tests.xml`及`evidence/safety-integration-tests-final.xml`。两批分别61项、82项通过，含重复用例；新增的完整高频采样流程使用明确标注的Mock。首次回归曾遇一次Windows checkpoint文件替换拒绝访问，单独复查及完整相关批次重跑均通过，没有为此扩大生产代码修改。

前端TypeScript/Vite生产构建通过。Chrome实际检查1440像素桌面与390像素手机布局无横向溢出；默认分类、物体辅助入口、跌倒全局问答、火光问答、证据展开和跳转均通过，无页面脚本错误。

## 使用与边界

打开`http://127.0.0.1:8000/`，刷新页面，点击“打开监测工作台”。选中火光录像即可查看本次新结果。新录像导入后点“开始 AI 分析”；其他旧录像要应用新采样需“重新分析”，不能继续旧配置检查点。

日请求上限保持60次，手动暂停和批次自动接续保留。密集采样会增加帧数与耗时，当前仅用于120秒以内短片。长片仍用0.5帧/秒、30秒窗、28秒步长及静止过滤；尚未实现长录像局部火光触发的自适应高频复查。24小时完整处理仍未验证。

本次为单个受控火源样本验证，不能据此声称真实家庭火灾、烟雾、火花或老人意外的总体识别准确率。当前仍为上传录像分析，没有实时摄像头或手机推送。
